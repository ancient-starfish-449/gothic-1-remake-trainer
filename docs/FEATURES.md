# Gothic 1 Remake Trainer — feature reference

Gothic 1 Remake Trainer uses a concise workspace for character settings, equipment groups, and quest notes. The feature map follows the same order as the project navigation.

| Section | Description |
|---|---|
| Character settings | Character-related parameters and the settings associated with the selected category. |
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Quest notes | A dedicated section for quest notes and the configuration details associated with that area. |

The project page follows the same section structure.
